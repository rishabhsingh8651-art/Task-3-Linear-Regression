# Task 3 - Linear Regression

## AI/ML Internship

## Objective

The objective of this task is to implement and understand Simple and
Multiple Linear Regression for house price prediction.

## Dataset

Housing Price Dataset.

The dataset contains different house-related features and the target
variable is house price.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Steps Performed

1. Loaded the housing dataset.
2. Explored the dataset.
3. Checked missing values and duplicates.
4. Performed statistical analysis.
5. Visualized the price distribution.
6. Created a correlation matrix.
7. Implemented Simple Linear Regression.
8. Implemented Multiple Linear Regression.
9. Converted categorical variables using one-hot encoding.
10. Split the data into training and testing sets.
11. Evaluated the models using MAE, MSE and R².
12. Visualized actual vs predicted prices.
13. Interpreted model coefficients.
14. Analyzed residuals.

## Evaluation Metrics

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- R² Score

## Conclusion

Linear Regression was used to predict house prices using the available
housing features. Both simple and multiple regression approaches were
implemented and evaluated.
